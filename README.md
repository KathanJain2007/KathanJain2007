### *I turn everyday problems into working software.*

I'm a 2nd year **Computer Science** student at **BMS College of Engineering, Bengaluru**. I like spotting real-world problems and building practical, user-focused solutions for them — especially with **AI agents, automation and data-driven apps**.

## 🚀 What I'm up to

- 🏆 Participated in **5+ hackathons** and reached the **finalist stage in 2**
- 🤖 Built **[Classroom Agent](https://github.com/KathanJain2007/classroom-agent)** — a 3-agent LangGraph pipeline that turns course notes into a verified exam paper and marking scheme
- 📦 Co-built **[Shelvo](https://github.com/KathanJain2007/CodeMaxxers-GridPoint)** — a warehouse location optimizer that cuts delivery cost by **31.9%** on Bengaluru demand data, [try it live](https://shelvo-codemaxxers.netlify.app)
- 📱 Built **[SpendTag](https://github.com/KathanJain2007/daily-balance)** — an offline Android expense tracker that reads bank/UPI SMS and learns your categories
- 🧠 Practicing **Data Structures & Algorithms in C++**
- 🌱 Exploring **AI/ML** and Python libraries for real-world applications
